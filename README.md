# Gideon Abiodun: QA Lead portfolio

Static site (HTML, CSS, JavaScript). No build step or dependencies.

## Run locally in VS Code
1. Open this folder in VS Code and install the **Live Server** extension.
2. Right-click `index.html` and choose **Open with Live Server** (port 5501 is preset in `.vscode/settings.json`).
   You can also double-click `index.html`; it works from the file system.

## Where to edit
| What | File |
|---|---|
| Name, title, tagline, intro, photo | `js/content.js` → `person` |
| Email, phone, GitHub, LinkedIn, WhatsApp, CV path, form endpoint | `js/content.js` → `links` |
| About text and headline stats | `js/content.js` → `about`, `stats` |
| Experience | `js/content.js` → `experience`, `otherExperience` |
| Skills | `js/content.js` → `skills` |
| Achievements | `js/content.js` → `achievements` |
| QA project cards | `js/content.js` → `projects` |
| Documentation samples | `js/content.js` → `documentation` (set `file`), files go in `assets/docs/` |
| Certifications and education | `js/content.js` → `certifications`, `education` |
| CV PDF | replace `assets/cv/Gideon_Abiodun_CV.pdf` |
| Photo | replace `assets/img/profile.jpg` |
| Colours (original black and pink) | `css/styles.css` → `:root` |
| Page title and SEO | `index.html` → `<head>` |

Text starting with `[` is a placeholder. Set `showPlaceholders: false` in `content.js` to hide them all.

`_archive/old-site/` holds the original web-design site and is not used. Delete it when you are happy.
